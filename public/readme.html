Testing Methodology

Automated Testing with Node-Fetch

The project includes a comprehensive testing suite (test.js) that validates all server functionality:

Testing Approach

  • Tool Used: Node-fetch for HTTP requests as required by specifications
  • Test Coverage: 18 automated tests covering all dynamic routes
  • Test Categories: Authentication, API endpoints, data persistence, error handling
  • Output Format: Clear pass/fail status printed to stdout as required

Test Suite Structure

// Example test structure from test.js async function testLogin() { const response = await fetch('http://localhost:5000/login', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ username: 'admin', password: 'admin' }) }); const data = await response.json(); return data.success === true; }

Testing Categories

  • Authentication Tests: Login, logout, registration, session management
  • Product API Tests: Product retrieval, search functionality
  • Cart API Tests: Add/remove items, quantity updates, persistence
  • Admin API Tests: Activity logs, product management, filtering
  • Error Handling Tests: Invalid requests, authentication failures

How to Run Tests

# Start server in one terminal node server.js # Run tests in another terminal node test.js # Expected output shows each test result: ✓ Test Login - PASSED ✓ Test Product Retrieval - PASSED ✓ Test Cart Operations - PASSED
