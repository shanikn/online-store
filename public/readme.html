1. Store Name

ShanikJewls - An online jewelry store specializing in handcrafted pieces.

2. What Am I Selling?

I'm selling handcrafted jewelry items including:

  • Gold earrings (drops, hoops, studs)
  • Bracelets (tennis, chain, bangles)
  • Rings with customizable sizing
  • Watches with engraving options
  • Wedding jewelry collections

Many items support customization like ring sizing and custom engraving.

4. Was the Project Hard to Do?

The project had several challenging parts:

  • Data Structure: Setting up individual user files instead of combined files took time to get right
  • Session Management: Implementing different cookie expiration times for "remember me" vs normal login was tricky
  • Product Customization: Building the modal system for ring sizing and engraving required careful state management
  • Search Functionality: Creating live search with dropdown results and keyboard navigation was complex
  • Admin Features: The activity filtering and product management required good planning

Overall it was challenging but manageable. The modular structure helped keep things organized.

6. How I Tested the Project

I used node-fetch to create automated tests in test.js. The testing approach:

Test Setup

  • Created test user accounts automatically
  • Used cookies to maintain sessions across test requests
  • Tested both success and error scenarios

Test Categories

Category Tests What I Tested
Authentication 4 tests Registration, login, logout, invalid credentials
Products 3 tests Get all products, search functionality, admin add/delete
Cart Operations 6 tests Add/remove items, update quantities, customization
Purchase Flow 4 tests Checkout creation, payment processing, order completion
Admin Features 3 tests Activity logs, username filtering, product management
Extra Features 4 tests Wishlist operations, profile updates, contact form

Running Tests: Use npm test to run all tests. Each test prints pass/fail status with details.

Manual Testing: I also tested the UI manually by:

  • Creating accounts and testing login/logout
  • Adding items to cart with different customizations
  • Completing full purchase flows
  • Testing search functionality
  • Verifying admin panel features
  • Testing all extra pages functionality
