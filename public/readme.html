For: RUNI 2025 FullStack Development Course

Built with: Node.js, Express, HTML, CSS, JavaScript

Project Overview

About This Project ✨

ShanikJewls is where my three greatest passions collide: the art of jewelry making, the beauty of web design, and the logic of coding! 💎 This isn't just a project for my FullStack course - it's a digital expression of my love for handcrafted gold jewelry and the endless possibilities of technology.

Every line of code I wrote was inspired by the way light catches on a perfectly polished piece of gold. The color palette wasn't just chosen - it was felt. Those warm creams and elegant golds aren't just CSS variables; they're the digital embodiment of the jewelry pieces I dream of creating.

💍 From the heart: Building this site taught me that coding is just another form of craftsmanship - each function carefully shaped, each design element thoughtfully placed, just like setting a stone in gold. This project works for both casual browsers and jewelry enthusiasts who want the full shopping experience with personalization!

Main Features

Shopping Cart

Add items to cart, update quantities, and proceed to checkout.

Wishlist System

Save items for later using the heart button on products.

Product Customization

Add custom engravings to bracelets and select ring sizes for rings.

User Authentication

Login system with session management and "remember me" option.

Admin Dashboard

Administrative interface for managing products and viewing user activity.

Search Functionality

Live search with dropdown results for finding products quickly.

User Roles

  • Guest Users: Can browse products and search the catalog
  • Registered Users: Full access to cart, wishlist, and product customization
  • Admin: Product management and activity monitoring (login: admin/admin)

Setup Instructions

Installation:
  1. Extract project files
  2. Run npm install
  3. Run node server.js
  4. Access at http://localhost:5000
  5. Default admin: username "admin", password "admin"
